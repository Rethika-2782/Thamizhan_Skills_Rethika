# ▶ Running the Projects

## User Management System

### Backend

```bash
cd User-Management-System/backend
npm install
npm start
```

### Frontend

```bash
cd User-Management-System/frontend
npm install
npm start
```

Frontend:

```text
http://localhost:3000
```

Backend:

